# 988 FM

A simple 988 FM Malaysia live-radio web app/PWA.

## GitHub Pages
Upload all files in this folder to the ROOT of your GitHub repository and make sure `index.html` is in the root.

## Oppo
Open the GitHub Pages URL in your browser and choose “Add to Home screen”. The shortcut uses the 988 logo.

## Playback
The page attempts to start playback automatically. If the browser blocks autoplay, press **PLAY 988**.
